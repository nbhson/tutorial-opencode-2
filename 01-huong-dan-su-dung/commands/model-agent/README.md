# Nhóm model-agent (3 lệnh) — đổi não + đổi vai + login giữa session

> **Dành cho:** người cần đổi model/agent không thoát session.

| Lệnh | Nó làm gì | Khi nào dùng | Chi tiết |
|---|---|---|---|
| `/models` | đổi model (`Ctrl+X M`, `F2` xoay nhanh) | việc dễ ↔ khó | [models](./models/README.md) |
| `/agents` | đổi agent primary (`Shift+Tab`) | code ↔ plan | [agents](./agents/README.md) |
| `/connect` | login provider / Zen / Go | thêm key, hết hạn mức | [connect](./connect/README.md) |

> Đổi agent không đổi model (2 thứ riêng). Đổi gì cũng không sửa config file.
